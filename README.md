# 电商全景系统 · 整体框架

将管理板块、行渠业务板块、行业板块等模块整合的集成性系统入口。

## 模块结构

- **第 1 层 · 管理板块**：服务商库（服务于行渠联动）、SAB 体系、合伙人体系、风控、业绩管理
- **第 2 层 · 行渠业务板块**：行渠联动、小单元机会、小赛道机会
- **第 3 层 · 底座**：知识沉淀（渠道电商组对内 / 行业 / 管理 / 产品系统）/ 工具（乐享 / 百宝箱 / 邮件组 / 群 / 鹅妹 / 渠道一站式平台）/ 信息系统运维

## 使用方式

1. 用浏览器打开 `index.html` 即可
2. 点击右上角「登录」→ 使用企业微信扫码完成身份认证
3. 点击任一板块卡片 → 跳转到对应平台
4. 点击卡片右上角的 ✎ 铅笔 → 编辑跳转链接与说明
5. 顶部「导出」备份配置 JSON

## 企业微信身份认证配置

系统使用企业微信扫码登录。需在 Vercel 项目 `Settings → Environment Variables` 配置以下环境变量：

| 变量 | 说明 | 获取方式 |
|---|---|---|
| `WEWORK_CORP_ID` | 企业微信 CorpID（企业ID） | 企业微信管理后台 → 我的企业 → 企业信息 |
| `WEWORK_AGENT_ID` | 自建应用的 AgentID | 应用管理 → 自建应用 |
| `WEWORK_SECRET` | 自建应用的 Secret | 应用管理 → 自建应用 → 查看 Secret |
| `DATABASE_URL` | Neon Postgres 连接字符串 | Neon 控制台 |

**关键步骤**：还需在企业微信管理后台 → 自建应用 → 「企业微信授权登录」中，将网站域名配置为**可信域名**（如 `ecominone.vercel.app`），否则扫码后会提示链接无法访问。

## 文件说明

- `index.html` - 页面结构
- `styles.css` - 样式（深色管理看板风格）
- `app.js` - 交互逻辑（登录 / 编辑 / 跳转 / 配置持久化）
- `api/config.js` - 配置数据读写接口（Neon Postgres）
- `api/auth.js` - 企业微信扫码登录认证接口
- `capability-map.html` - 服务商能力库指标三层下钻图谱
